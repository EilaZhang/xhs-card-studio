# 稿件写作规范

怎么写稿，出图才好看。核心就一句：**把 `##` 当成「一页」来用。**

## 分页怎么走

三种控制方式，可以混用：

| 你写的 | 结果 |
| --- | --- |
| `# 标题` | 封面页，只放标题和紧随的一句副标题 |
| `## 小节名` | 开一张新卡（主要分页方式） |
| 单独一行 `---` | 在这一刀切下去，强制分页 |
| 单独一行的数字 `1` `2` `3` | 同样强制分页（Markdown 里没这语义，但 Obsidian 笔记里很多人拿它标页码，所以认） |
| 什么都不写 | 按卡片**实际可用高度**自动算容量，在段落边界自动切 |

`1 2 3` 这种分页要生效，**全篇得出现 2 次以上**——否则正文里孤零零一个数字会被误判。嫌它干扰，就统一改用 `---`。

**推荐节奏**：`# 大标题` 开篇 → 每个 `##` 一页 → 需要留白的地方插 `---`。

## 直接拿 Obsidian 笔记出图

不用改稿，Obsidian 的记法原样认：

| Obsidian 写法 | 说明 |
| --- | --- |
| `![[图.png]]` | 图片嵌入，自动找文件 |
| `![[图.png\|400]]` | 指定宽度 400px，高度按比例 |
| `==高亮==` | 变成强调底色 |
| 行尾直接跟图片 | 会自动拆成「文字 + 图」两块 |

**附件放哪都能找到**：从稿件所在目录逐级往上找，一直找到 vault 根。所以笔记放在子目录（比如 `日记/`）、图扔在 vault 根目录，不用挪。

**找不到图**时终端会打印 `[warn] 找不到图片，将留空占位`——图位会留白但不报错，出图后扫一眼这条警告就行。

**`![[某某.html]]` 这类非图片嵌入不支持**，会被跳过并警告。卡片只吃图片：要么先把网页截成图，要么在稿子里改成一句引导文案。

一页放多少字舒服？**120～220 字**。低于 80 字会显得空，高于 260 字开始挤。

## 卡片类型

系统会自动判断每页该用哪种版式：

| 类型 | 什么时候触发 | 版式 |
| --- | --- | --- |
| 封面 | 第一页且以 `#` 开头 | 大标题居中，副标题跟在下面 |
| 金句 | 整页只有一句引用，或一句不到 56 字的短句 | 大字号居中 |
| 内容 | 其余情况 | 标题在上，正文从上往下排，内容少的自动居中 |
| 清空 | 只有标题没内容 | 会被合并到相邻页，避免空卡 |

想强制出金句页，把那一页只留一句 `> 引用` 就行。

## 语法对照

```markdown
**加粗**          强调重点，用在关键结论上
*斜体*            降级强调，少用
==高亮==          荧光笔效果，一页最多用一处
`行内代码`         等宽字体，适合参数、命令
> 引用            大字号 + 竖条，适合金句
```

## 配图

```markdown
![配图说明](images/screenshot.png)
```

- 路径**相对于稿件文件所在目录**，不是相对于输出目录
- 图片独占一段时才能撑满整宽；混在文字段落里会跟着文字走
- 单张图最高按皮肤设定（默认 720px）等比缩放，**不裁切**
- 图片的**边框风格**单独用 `--frame` 选（细描边 / 相纸框 / 无边框），也可以在 front-matter 里写 `frame: paper` 把这个稿子固定成相纸框；圆角跟着皮肤走
- 一页放几张图取决于图的**真实高度**，分页器会算；小图可以两三条挤一页，大截图往往一张就占满

## 常见坑

| 坑 | 后果 | 怎么避 |
| --- | --- | --- |
| 用 `##` 当排版装饰 | 每节都变独立页，切得很碎 | 装饰性的小标题用 `###` |
| 一个自然段写 400 字 | 自动按句号切开，可能切在怪地方 | 自己按语义分段 |
| 图片路径写绝对路径 | 换台电脑就断 | 用相对路径，图放稿件旁边 |
| front-matter 的 `---` 和分页的 `---` | 搞混了会把配置切碎 | front-matter 只在文件最开头写一次 |
| 全篇只有 `#` 没有任何 `##` | 会按字数自动切，切点不完全可控 | 加 `---` 手动控制 |

## 出图后怎么改

| 想改什么 | 怎么做 |
| --- | --- |
| 某页文案 | 改稿件，重新跑 `build-cards.mjs` |
| 分页位置 | 加 / 删 `---` |
| 每页容量 | 默认按卡片高度自动算，一般不用管。想手动干预：`--max-chars 300`（切更碎）或 `420`（装更满） |
| 某页只有一张图、太空 | 会自动试着并进相邻页；还不行就把相邻的文字挪过来 |
| 配图边框风格 | 出图时加 `--frame paper`（相纸框）/ `--frame none`（无边框），不写就是细描边 |
| 配色字体 | 打开 `templates/theme-tuner.html` 调，或改 `assets/themes/default.css`（奶油蓝，默认皮肤）。想整套换：`--theme 知识风` |
| 只重渲某一页 | `render.mjs ... --only 3` |
